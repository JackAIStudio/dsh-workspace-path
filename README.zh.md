# dsh-workspace-path（工作区中心 & 顶部会话工作区/会话 ID 胶囊）

侧栏底下一颗文件夹图标：一键呼出工作区快速中心；同时在每一个正在对话的会话顶部 Header 紧随标题展示当前工作区胶囊徽章与会话 ID 芯片，无论处于「单列表」还是「按工作区分组」模式，都能一目了然看清当前所属工作区与当前会话身份！

## 功能特性

### 1. 顶部 Header 独立会话 ID 芯片与 Popover 浮层（0.3.1 新增）
- **短 ID 秒核对**：工作区胶囊右侧常驻一个极简等宽芯片 `[ # 5f9c5594 ]`，抬头一眼就能核对当前会话 ID。
- **悬停 Popover 气泡**：鼠标悬停即可展开浮动卡片，清晰查看会话名称、完整的 UUID（`session-...`）。
- **一键复制与新窗口直达**：
  - 📋 **复制完整会话 ID**：卡片内一键复制，按钮即时反馈“✓ 已复制”，点击顶栏芯片本身也直接秒复制。
  - ↗ **在新独立窗口中打开**：直接在独立新窗口中打开此会话，当前工作流丝毫不受打扰。

### 2. 顶部 Header 工作区胶囊徽章
- **单列表与分组全兼容**：在单列表（Flat List）模式下，再也不用担心“不知道当前会话在哪个项目目录”。
- **自然对齐原生风格**：紧邻会话标题右侧（在 Preset 预设标签左侧），展示 `📁 工作区短名 ▾`。
- **悬停信息卡片**：鼠标悬停即可查看工作区名称、系统绝对物理路径（POSIX 环境自动以 `~` 智能缩写）。
- **点击快捷菜单**：
  - 📋 **复制绝对路径**：一键将当前会话工作区的完整物理路径复制到剪贴板。
  - 📂 **在访达/资源管理器中显示**：直接在系统桌面打开该目录。
  - 💻 **在终端中打开**：直接调起系统原生终端并在该工作区目录就位。
  - ➕ **在此工作区新建会话**：不用去侧边栏翻找，直接在当前工作区极速新建一个全新会话。

### 3. 侧边栏工作区快速中心
- **点击切换**：点击列表中任意工作区行，直接切换并开启该工作区的新会话，无缝直达目标工程。
- **建子目录工作区**：搜索栏右侧 `➕` 按钮，一键在当前活跃工作区下快速新建子目录并自动注册为工作区开会话。
- **轻量快捷操作**：
  - 📋 **复制路径**：点击行内复制按钮，将绝对路径拷贝到剪贴板。
  - 💻 **终端打开**：在系统原生终端中定位到该工作区。
  - 📂 **访达/资源管理器**：在本地文件管理器中直接定位（Reveal）。
- **极速搜索**：支持拼写、中文、短路径、波浪号路径模糊搜索，回车直接进入首项结果。

## 安装

```sh
# 开发机（软链接）
dsh plugin --profile web add link:$HOME/Documents/dshspace/plugins/dsh-workspace-path

# 新电脑（GitHub 仓库）
dsh plugin --profile web add github:JackAIStudio/dsh-workspace-path
```

只改客户端代码（`client.js`）**刷新浏览器页面**（Cmd/Ctrl+R）即可生效，无需重启 `dsh web`。
