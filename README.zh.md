# dsh-workspace-path（工作区中心 & 顶部会话工作区/会话 ID 胶囊）

侧栏底下一颗文件夹图标：一键呼出工作区快速中心；空白会话输入框上的官方工作区选择器也被同一套列表接管。默认只列出你手动加过的**项目**工作区；`days/YYYY-MM-DD` 这种按天草稿纸收在第二步。今天要开新会话，继续点左上角「新会话」。

## 功能特性

### 0. 官方侧栏「默认只看项目」（0.7.0）

- **按天目录自动收起**：左侧官方列表里 `days/YYYY-MM-DD` 的日期组默认隐藏，项目工作区占第一屏；今天和**当前打开会话所在的工作区**始终保留，不会让正在看的会话从列表里消失。
- **一行状态条**：固定在「会话」区头和列表之间，显示 `项目 22  已收起 58 个按天目录`，点开可切「只看项目 / 全部工作区」，或直达工作区中心的按天页。
- **搜索照常穿透**：在官方搜索里输入日期或会话名，结果覆盖全部工作区，不受筛选影响；搜索期间状态条自动让位。
- **纯展示层**：只给官方列表加/去一个 class，不改 `workspace.json`、不删目录、不动会话归属；切回「全部工作区」立刻还原。
- **按工作区 / 按工作区树 / 单列表三种分组都生效**（单列表下改为隐藏这些会话行）。

### 1. 项目优先的工作区选择器（0.4.0）

- **默认只看项目**：JackDSH、JackAICutWeb 这类代码库在第一屏，不再和日期目录混排。
 - **最近用过与快捷操作优先**（0.6.1）：除了会话活动，无论点击行内的「复制路径、Git、启动命令、终端、在访达打开」，还是点击工作区本身，都会计入使用并更新时间戳与频次；打开选择器时最常用与最近使用的项目自动排在最前面。
- **按天是第二步**：底部 `按天工作区 (N)` 才展开日期列表，今天置顶。
- **搜索仍能命中日期**：在项目视图里输入 `09-07` 也能直达那天，不用先切过去。
- **两处同一套**：侧栏文件夹中心，以及空白会话里那颗工作区芯片，都走这套分类。

### 1.1 新会话页（Hero，0.7.1）

- **选择器行内动作与工作区中心一致**：新会话输入框上方的项目列表，每行同样带复制路径、Git、启动命令、终端、在访达打开；挑项目时不必先进工作区中心。
- **Hero 的 Git 按钮真正打开「文件变动」页**：按钮现在会带上当前工作区与主视图会话，并接上 Better Sidebar 服务；只在 Better Sidebar 不可用或该页被禁用时才回退外部终端。
- **仍是同一套数据**：按天目录、搜索、最近使用排序、`＋` 添加工作区都与侧栏工作区中心完全共用。

### 2. 顶部 Header 独立会话 ID 芯片与 Popover 浮层

- **短 ID 秒核对**：工作区胶囊右侧常驻一个极简等宽芯片 `[ # 5f9c5594 ]`。
- **悬停 Popover**：查看会话名称、完整 UUID；可复制 ID，或在系统浏览器中打开该会话。

### 2.1 顶栏「Web」按钮：在系统浏览器打开（0.8.0）

- **一键切到默认浏览器**：会话头部右上角多一颗 `Web` 按钮，用系统默认浏览器打开当前会话的 Harness 界面。
- **带鉴权**：地址由宿主用真实回环端口和本次进程的 launch token 组装，打开不会停在 401；带 `#session=`，装了 `dsh-session-navigator` 时直达当前会话。
- **桌面端可用**：桌面 App 的页面来自私有 `dsh-app://` 协议，相对路径交给系统只会唤回 App 自己；这里统一走带 token 的回环地址。
- **与 ID 浮层共用一份实现**：Popover 里的「在系统浏览器中打开」走同一个 URL 组装，此前那条菜单用的是相对路径。

> 本节由独立插件 `dsh-open-in-browser` 合并而来。宿主端在 `open-web.js`，前端在 `client/open-web.js`；原来那个仓库不再需要单独安装。

### 3. 顶部 Header 工作区胶囊徽章

- 紧邻会话标题右侧展示 `📁 工作区短名 ▾`。
- 点击可复制路径；行内 `＋` 在此工作区新建会话。（Git / 启动命令按钮已迁到右上角，见 §5）

### 4. 侧边栏工作区快速中心

- 点击列表行：切换并在该工作区开新会话。
- **搜索栏右侧 `➕` 与官方「添加工作区」同一条路（0.6.0）**：直接调起 DSH 自带的目录选择器——本机是 macOS 原生选择框（自带「新建文件夹」），远程/无头环境是应用内浏览对话框（同样能新建文件夹）；选中目录后登记为工作区并打开。不再有插件自己的「子目录名称 / 创建并进入」内联表单。
- 行内复制路径 / 终端 / 访达。

### 5. 会话头部右上角大号 Git / 启动命令（0.5.0）

- **两个高频按钮放大归位**：Git 与启动命令从会话标题旁迁到会话头部右上角，28px 大号图标（对齐官方头部按钮的尺寸手感）。同一排右侧还有 `Web` 按钮（见 §2.1）。
- **Git 按钮可配置**：左键默认在 Better Sidebar 打开当前会话的「文件变动」页；右键菜单可切换为「在外部终端运行 git status」，选择全局记住；Better Sidebar 不可用时自动回退外部终端。
- **启动命令**：左键运行已保存的 dev 命令（未设置时弹出设置框），右键修改。

### 6. 工作区列表的 git 工作区状态（0.5.0）

- 工作区中心里每个 git 项目显示工作区状态：`✓` 干净 / `● N` 未提交改动 / `?` 探测失败；非 git 目录不显示。
- 打开面板时异步批量探测（5 秒缓存、并发与超时保护），结果回来前列表照常渲染。

## 安装

```sh
# 开发机（软链接）
dsh plugin --profile web add link:$HOME/Documents/dshspace/plugins/dsh-workspace-path

# 新电脑（GitHub 仓库）
dsh plugin --profile web add github:JackAIStudio/dsh-workspace-path
```

改 `client/` 或 `paths.js` 后先跑 `npm test`（会 pack 进 `client.js`），然后**刷新浏览器页面**（Cmd/Ctrl+R）即可，无需重启 `dsh web`；改 `index.js` / `git-summary.js` 等 host 端文件需要**重启 `dsh web`** 才生效。
